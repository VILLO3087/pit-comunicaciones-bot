# PIT COMUNICACIONES — Backend inicial

Backend de prueba con Express para Railway.

## Endpoints
- `GET /` — estado general
- `GET /health` — comprobación de salud
- `GET /api/business-info` — información comercial aprobada
- `POST /api/test-message` — prueba de recepción de texto; no guarda datos

Railway detectará `package.json`, instalará dependencias y ejecutará `npm start`.

**Esta es una base técnica inicial, no un bot terminado.** No incluye autenticación, base de datos, IA, WhatsApp ni gestión real de clientes. No introducir datos personales ni comprobantes.
